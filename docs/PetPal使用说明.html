PetPal 使用说明

一只待在桌面上的洛天依桌宠，附带好感度、每日图片、聊天、音乐播放器与设置面板。免安装，不联网也能用。

一、怎么运行

1. 系统要求：Windows 10 / 11（64 位）。

2. 解压整个文件夹后，双击 PetPal.exe。桌宠会出现在桌面上，右下角托盘出现图标。

3. 请保留整个文件夹 —— exe 依赖同目录的 DLL 与 resources 文件夹，只拷 exe 一个文件是跑不起来的。

二、基本操作

操作 效果
左键按住拖动 把它拎起来；松手后自由落体到屏幕底部
左键单击 摸摸它，好感度 +1
右键单击 弹出功能菜单（见下）
托盘图标（双击 / 右键） 恢复桌宠、退出程序

右键菜单内容：和我聊天、打开面板、开心一下、走两步、坐下休息、睡觉、挥手、思考、吃东西、喝水、生气、飞行、暂停自动行为、恢复自动行为、隐藏到状态栏、退出。

「暂停自动行为」会让它待在原地不动；「隐藏到状态栏」只是把它收起来（之后可从托盘「恢复」），只有点「退出」才是真正关闭程序。

三、面板的五个页面

· 好感度：当前等级、称号与今日剩余互动次数，也可以在这里重置。

· 每日图片：每天固定抽一张插画，双击可以看原图。

· 聊天：和它打字聊天，也可以让它接歌词。

· 播放器：扫描本地音乐，也可联网搜索（网易云 / B 站），带逐句歌词。

· 设置：界面字号、主题配色与背景图、桌宠大小、桌面歌词开关、重置好感度。

四、换成自己的内容

每日图片：把 jpg / png 图片放进 resources\daily_image\，重启程序即可看到。

歌词库：在 resources\songs\ 里新建一个 .txt，按下面格式填写，歌词直接粘贴即可。

title: 歌名
artist: 歌手
tempo: fast  （或 slow，快歌 / 慢歌二选一）

seg:
第一句歌词
第二句歌词

五、数据在哪 / 怎么卸载

好感度、收藏与外观设置保存在 %APPDATA%\PetPal\，删掉就能恢复初始状态。

卸载 = 直接删除整个 PetPal 文件夹即可，程序不写注册表、不残留后台服务。

六、已知限制

· 联网搜索走的是社区非官方接口，平台改版可能导致搜索失效；本地功能完全不受影响。

· B 站音频依赖 Windows 自带的 Media Foundation 转换，个别资源可能解码失败（列表行上会提示）。

· 网易云 VIP / 付费歌曲没有可播放直链，搜索结果里已直接过滤，不会显示。
