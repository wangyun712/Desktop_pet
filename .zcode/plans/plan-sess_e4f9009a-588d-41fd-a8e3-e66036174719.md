实现两个改动：①在线流式播放（不落盘、点一下 1~2 秒出声）；②桌面歌词锁定后鼠标穿透。

## 改动一：在线流式播放（仅网易云 MP3；B 站保持"先转码后播"）

### 1. `StreamFeed`（AudioPlayer.cpp 内部类，AudioPlayer.h 前置声明）

后台顺序下载器 + 带锁缓冲，给解码器当"数据源"：

- 下载在主线程（QNetworkAccessManager `readyRead` 增量追加，和 OnlineMusic 同款），缓冲/位置用 `QMutex` 保护，`QWaitCondition` 让音频线程等待补货
- 状态：`baseOffset`（缓冲首字节对应文件偏移）/ `buf` / `totalSize`（Content-Length）/ `finished` / `stopRequested`
- **read 回调**（音频线程）：区间内直接给；需要未下载的数据 → 等补货（deadline 5 秒，超时给短读）；下载线程挂了 → 给短读让播放自然结束
- **seek 回调**：目标在已缓冲区间内 → 直接移；跳到未下载处 → 清缓冲、`baseOffset = 目标`、发 queued 信号让主线程用 `Range: bytes=N-` 重启下载（向后跳回已缓冲区不重启）
- 到达 `totalSize` → read 返回 0 → 解码器 EOF → 现有 `reachedEnd`/`trackFinished` 链路自然接手

### 2. `AudioPlayer::loadOnline(url, durationMs, headers)`

- 复用现有停止/销毁顺序（设备停 → 解码器 uninit），解码器改 `ma_decoder_init(readCb, seekCb, feed, &cfg, &decoder)`（dr_mp3 默认启用，无需选择代码）
- `m_durationMs` 直接用搜索结果带的时长（流式拿不到总长）；`playedFrames`/seek/进度轮询/`trackFinished` 全部不動
- `stop()`/`load()`/析构：先停设备（音频线程退出）再销毁 StreamFeed

## 改动二：桌面歌词锁定后鼠标穿透

`DesktopLyrics::paintEvent`：那层 alpha=1 的"大判定框"**只在未锁定时铺**。锁定时撤掉它 → 分层窗口按像素 alpha 命中：只有歌词笔画像素（alpha>0）能接住鼠标（**双击笔画解锁仍然可用**），笔画之间的空白全部穿透到下层窗口。工具条/拖拽本来就被锁定挡住，行为不变。

## 接线（PlayerPage）

- `playLibraryIndex`：路径以 `http` 开头 → `m_player->loadOnline(url, 时长, 按域名取 Referer 头)`（不存在的文件守卫不再误伤）
- `fetchAndPlay` 网易云分支：`play && 临时目录` → **流式**（库行 path=url、标"在线"、清联网区、异步拉网易歌词重建逐句歌词）；**收藏/仅下载不变**（完整下载到储存盘，永久保留）
- `loadLyricsAndCover` 对 URL 路径不崩（已核实：TrackMeta 静默返回空 Meta → 兜底封面 + 提示，随后异步歌词回调补上真实歌词）
